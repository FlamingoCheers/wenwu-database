## 与本库 Schema 的映射

| 国博字段 | 本库字段 | 备注 |
|---|---|---|
| 年代 | `dynasty` | 词表已覆盖（"商周时期"归 东周 或映射为 商+西周 区间，需人工规则） |
| 质地 | `material` + `category` | 质地→material 直取；质地+品类组合映射 category 受控词 |
| 品类 | `category` 参考 | 国博品类分类学不同（按功能），映射时以质地+名称关键词为主 |
| 名称 | `name` | OCR 后需人工复核生僻字 |
| 详情页 | `source_url` | 截图时记录页面 URL |

## B 类采集流程设计（待实现 collectors/nmc_collector.py）

1. Playwright 有头模式打开列表页 → 按年代轴逐组筛选 → 逐页"加载更多"
2. 点开每件文物详情页：
   - 整页截图 → OCR 提取名称/年代/质地/介绍文字
   - 点击文物大图 → 截取放大视图（带水印可接受）→ 存 `data/images/NMC-{id}/`
3. 节奏控制：单日限量（建议 ≤100 件）、随机间隔 3–8 秒、失败进人工队列
4. OCR 低置信字段标 `needs_review: true`；`credit` 强制 "中国国家博物馆"（官网截图，版权归馆藏机构）
5. `relic_id` 规则：详情页 URL 中通常含数字 ID，无则用日期+序号生成 `NMC-YYYYMMDD-NN`

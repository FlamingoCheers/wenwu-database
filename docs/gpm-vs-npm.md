# 北京故宫 vs 台北故宫 —— 收藏对比与精品引入策略

> 生成于 2026-09-24，服务于 ROADMAP 2.9（北京故宫精品子集）。
> 结论先行：**两岸故宫同源（清宫旧藏），NPM 精品密度高但数量少；GPM 数量大、明清书画与官窑独有性强。我们只引 GPM 中 NPM 没有的内地精品，同名/同类重复一律只放跳转链接。**

## 一、库内台北故宫现状（数据实证，11,302 件）

- 类目：钱币 5,674 / 书画 2,685 / 瓷器 1,481 / 玉器 690 / 青铜器 516 / 文房 80 / 碑帖 49 / 宗教造像 46
- 朝代：元 4,130 / 宋 3,966+1,419(北宋)+258(南宋) / 唐 854 / 明 105 / 金 125 / 五代十国 89
- 结构性偏科：宋元书画与法帖是采集主线（分轴批任务所致），钱币占比过半（open data 列表排序产物）。

## 二、两岸收藏的公认差异（馆藏通识，用于选品策略）

| 维度 | 台北故宫（NPM，约 70 万件） | 北京故宫（GPM，约 186 万件） |
|------|------------------------------|------------------------------|
| 来源 | 1933-49 年清宫旧藏迁台精华 | 留守清宫藏品 + 1949 后购藏/捐赠/考古调拨 |
| 顶级书画 | 宋画三山（溪山行旅/早春图/万壑松风）、富春山居无用师卷、快雪时晴帖 | 清明上河图、千里江山图、五牛图、步辇图、韩熙载夜宴图、伯远帖 |
| 瓷器 | 汝窑 21 件（全球最集中）、宋五大名窑 | 明清官窑（洪武至宣德青花、成化斗彩、康雍乾三朝）体量全球第一 |
| 青铜 | 毛公鼎、散氏盘、宗周钟 | 后母戊鼎（调拨国博）、莲鹤方壶（与豫博各一）、三羊尊等 |
| 独有门类 | 翠玉白菜、肉形石、多宝格 | 大禹治水图玉山、金瓯永固杯、明清钟表、清代宫廷服饰、约 2 万片殷墟甲骨、清宫档案 |
| 明清宫廷画 | 少（迁台时明清画未被重视） | 数万件（如意馆画师、帝后肖像） |

**判断**：GPM 相对 NPM 的净增量集中在 ①明清书画与宫廷画 ②明清官窑瓷器 ③清代工艺（玉/钟表/服饰/漆器）④书法（伯远帖等）。NPM 已充分覆盖 宋元书画、宋窑、青铜礼器。

## 三、跨馆去重实测（2026-09-24，pipeline/dedup_cross.py）

- 30,055 件 → 规范化名称（繁转简+去标点）分组 15,725 → **跨馆同名仅 272 组**，其中 CJK 名 4 组（玉童子 12、玉兔 4、开元通宝钱 2、五铢钱 2），其余为英文泛称噪音（bowl/horse 等，已可用停用词+词数规则过滤）。
- **结论：库内真重复≈0**，各馆藏品互不重复；"去重"对海外馆无意义，对 GPM 的意义在于**引入前过滤与 NPM 同名者**。

## 四、GPM 精品引入策略（ROADMAP 2.9）

1. **采集**：`gpm_collector.py`，playwright 渲染 digicol.dpm.org.cn 列表/详情页（不逆向加密接口，读渲染后 DOM），同国内限速 100 件/6h，cron 滴灌。
2. **选品范围**（控制总量 3,000-5,000 件，1-2 个月收完）：
   - 明清书画/宫廷画（NPM 明清仅 105+11 件，缺口最大）
   - 明清官窑瓷器精品
   - 清代玉器/漆器/珐琅/钟表/服饰 代表作
   - 书法名品（伯远帖等）
3. **去重闸门**：入库前用 `dedup_cross.norm()` 规范化名称与 NPM 全集比对——同名直接跳过（页面仅存 source_url 跳转），朝代相容性二次校验（复用 audit_dynasty.COMPAT）。
4. **落地形态**：GPM-{编号}.json，museum=故宫博物院，无开放图片版权 → images=[]，detail 页存源链接；前端详情页显示"前往故宫官网"跳转。

## 五、验收标准
